### Email Filing URL Exhibit Exclusion Fix ✅ (2025-12-30)

#### Approach
Fixed email filing links pointing to exhibit files instead of main documents by implementing priority-based document selection.

#### Steps Completed
1. ✅ **Root Cause Analysis**
   - `extractPrimaryDocumentUrl()` was selecting exhibit files alphabetically before main documents
   - Simply picked the first HTM file that wasn't an index

2. ✅ **Priority-Based Selection Implementation**
   - Added `isExhibitFile()` helper: Detects exhibit patterns via regex (`ex21`, `exh31`, `dex21`, `-ex31`, `exhibit`)
   - Added `isMainDocument()` helper: Identifies main documents (ticker-YYYYMMDD.htm pattern)
   - Implemented 3-tier priority system:
     - Priority 1: Main document pattern (non-exhibit)
     - Priority 2: Any non-exhibit HTM file
     - Priority 3: Fallback to first HTM (may be exhibit)

#### Verification Results
- ✅ Tested extraction with real SEC 8-K filing - correctly selected `d13958d8k.htm` over `d13958dex21.htm`
- ✅ 6 test emails sent for all form types
- ✅ Fix applies to NEW filings (existing incorrect URLs remain until cache expires)

#### Files Modified
